# PLATFORM x y width height
# POINT x y
# MOVING x y width height pathX pathY speed
#   A moving platform starts with its top-left at (x, y), slides pathX right
#   and pathY down (negative = left/up), then slides back. speed = pixels per update.
#   MOVING lines are read by MovingPlatformLoader; LevelLoader skips them.
# LORE any text
#   A line of story shown when the level starts. Read by LevelLore; LevelLoader skips it.
